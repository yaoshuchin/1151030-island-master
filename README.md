# 我要當島主！從零開始，造島成真

> **💡 來自亮亮老師1151030**

本專案為「我要當島主！從零開始，造島成真（AI 造島 · 3D 島嶼網站 · GODOT）」課程教材網站鏡像備份版。
已解除密碼保護，開箱即可直接瀏覽完整課程單元、電子書、教材檔案與提示詞庫。

## 課程亮點
- **U00～U08 完整單元**：開場島主的一天、造島工坊導覽、選島型、島嶼清單、外觀配色、造島包下載、交給 AI 蓋島、第二次更新、讓島更好看。
- **線上電子書閱讀器**：內建九大單元高解析 PDF 翻頁閱讀器（免登入直接閱讀）。
- **完整資源庫**：含提示詞文字檔、範例模型與專案包（zip）、資料表（xlsx）、架構導覽等。

## 目錄結構
- `index.html`：課程首頁（免密碼直連版）
- `reader.html`：各單元高解析電子書線上閱讀器
- `assets/`：網頁樣式表、腳本、卡片與導覽圖片資源
- `_bk/`：各單元完整電子書二進位檔（PDF 規範）
- `code/`：各單元作業教材、提示詞與造島資源壓縮包
